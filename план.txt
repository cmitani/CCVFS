  ---
  ContainerHeader.cs                                                                                                                                                        
  Шапка файла-контейнера. Хранит метаданные.                                                                                                                                
  Поля:
  - Magic — 8 байт, "CCVFS100"
  - Version — число, сейчас = 1
  - Salt — 16 случайных байт для вывода ключа
  - TotalBlocks — сколько всего блоков данных в контейнере
  - DirectorySize — размер зашифрованного списка файлов в байтах (нужно чтобы знать сколько читать)
  - HmacHash — 32 байта, контрольная сумма всего файла

  Методы:
  - Write(BinaryWriter) — записать все поля по порядку в файл
  - static Read(BinaryReader) — прочитать все поля по порядку, вернуть объект
  - Validate() — проверить что Magic совпадает с ожидаемым, Version поддерживается

  ---
  FileEntry.cs

  Запись об одном файле внутри контейнера.

  Поля:
  - Name — имя файла, например "фото.jpg"
  - OriginalSize — настоящий размер в байтах (нужен чтобы обрезать последний блок при извлечении)
  - CreatedAt — дата добавления
  - Blocks — массив целых чисел, например [3, 7, 12] — в каких именно блоках лежат данные этого файла

  Методы:
  - Write(BinaryWriter) — записать поля
  - static Read(BinaryReader) — прочитать поля, вернуть объект

  ---
  BlockBitmap.cs

  Карта занятых и свободных блоков данных.

  Поля:
  - _used — внутренний массив bool, один элемент = один блок

  Методы:
  - BlockBitmap(int totalBlocks) — конструктор, создать массив нужного размера (все false = всё свободно)
  - IsUsed(int blockIndex) — занят ли блок
  - SetUsed(int blockIndex) — пометить блок как занятый
  - SetFree(int blockIndex) — пометить блок как свободный
  - FindFree() — пройти по массиву, вернуть первый свободный индекс. Если нет — бросить исключение "контейнер заполнен"
  - FreeCount() — сколько свободных блоков осталось
  - Write(BinaryWriter) — записать массив в файл
  - static Read(BinaryReader, int totalBlocks) — прочитать массив из файла, вернуть объект

  CryptoHelper.cs

  Всё что связано с криптографией. Статический класс, методы вызываются из ContainerManager.

  Методы:
  - DeriveKey(string password, byte[] salt) → byte[] — взять пароль + соль, вернуть 32-байтный ключ через PBKDF2 (твой уже готовый код)
  - DeriveKey(string password, byte[] keyFileBytes, byte[] salt) → byte[] — то же самое но с ключевым файлом: XOR пароль с SHA256-хешем файла, потом в PBKDF2
  - EncryptBlock(byte[] key, byte[] plaintext) → (nonce, tag, ciphertext) — зашифровать блок, вернуть три массива
  - DecryptBlock(byte[] key, byte[] nonce, byte[] tag, byte[] ciphertext) → byte[] — расшифровать блок, вернуть данные. Если тег не совпал — AesGcm сам бросит исключение
  - ComputeHmac(byte[] key, byte[] data) → byte[] — посчитать HMAC-SHA256
  - VerifyHmac(byte[] key, byte[] data, byte[] expectedHmac) → bool — проверить HMAC через FixedTimeEquals (защита от timing-атак)

  ContainerManager.cs

  Главный класс. Управляет контейнером. Все публичные операции здесь.

  Приватные вспомогательные методы:
  - BlockOffset(ContainerHeader header, int blockIndex) → long — посчитать на каком байте в файле находится нужный блок. Формула: размер шапки + размер битмапа + размер
  директории + blockIndex × размер одного блока
  - LoadDirectory(FileStream fs, byte[] key, ContainerHeader header) → List<FileEntry> — прочитать зашифрованный список файлов из файла, расшифровать, десериализовать
  - SaveDirectory(FileStream fs, byte[] key, ContainerHeader header, List<FileEntry> files) — сериализовать список файлов, зашифровать, записать обратно в файл
  - UpdateHmac(FileStream fs, byte[] key) — пересчитать и записать HMAC в шапку после любого изменения
  - ReadBlock(FileStream fs, long offset) → (nonce, tag, ciphertext) — прочитать один зашифрованный блок из нужной позиции
  - WriteBlock(FileStream fs, long offset, byte[] nonce, byte[] tag, byte[] ciphertext) — записать один зашифрованный блок в нужную позицию

  Публичные методы:
  - Create(string path, int sizeMb, string password, string? keyfilePath) — создать новый пустой контейнер:
    - сгенерировать соль
    - вывести ключ
    - записать шапку
    - записать пустой битмап
    - зашифровать и записать пустой список файлов
    - выделить место под блоки данных
    - посчитать и записать HMAC
  - Open(string path, string password, string? keyfilePath) — проверить что контейнер валидный:
    - прочитать шапку
    - проверить magic
    - вывести ключ из соли и пароля
    - проверить HMAC (если не совпадает — неверный пароль или файл повреждён)
    - вернуть... можно объект ContainerSession со всем внутри
  - AddFile(string containerPath, string password, string? keyfilePath, string sourceFilePath) — добавить файл в контейнер:
    - открыть контейнер, вывести ключ, проверить HMAC
    - прочитать битмап и список файлов
    - проверить что файл с таким именем не существует
    - прочитать исходный файл целиком в память (или блоками)
    - параллельно зашифровать все блоки через Parallel.For
    - для каждого блока: FindFree() → WriteBlock() → SetUsed()
    - добавить FileEntry в список
    - SaveDirectory, обновить битмап, UpdateHmac
  - ExtractFile(string containerPath, string password, string? keyfilePath, string fileName, string destPath) — извлечь файл:
    - открыть контейнер, проверить HMAC
    - найти FileEntry по имени
    - для каждого блока из entry.Blocks: ReadBlock() → DecryptBlock()
    - записать все расшифрованные данные в destPath, последний блок обрезать до OriginalSize
  - DeleteFile(string containerPath, string password, string? keyfilePath, string fileName) — удалить файл из контейнера:
    - найти FileEntry
    - для каждого блока из entry.Blocks: SetFree() — просто освободить место (данные остаются, но перезапишутся потом)
    - удалить FileEntry из списка
    - SaveDirectory, обновить битмап, UpdateHmac
  - ListFiles(string containerPath, string password, string? keyfilePath) → List<FileEntry> — вернуть список файлов внутри контейнера
  - CheckIntegrity(string containerPath, string password, string? keyfilePath) → bool — просто проверить HMAC и вернуть результат

  MainForm.cs (Windows Forms, в последний день)

  Контролы на форме:
  - ListBox — список файлов внутри открытого контейнера
  - TextBox для пути к контейнеру
  - TextBox для пароля (маскированный)
  - CheckBox + TextBox для ключевого файла
  - ProgressBar для долгих операций
  - Label для статуса

  Кнопки и что каждая делает:
  - Создать контейнер → диалог выбора пути + ввод размера → ContainerManager.Create
  - Открыть контейнер → диалог выбора файла → ContainerManager.Open → заполнить ListBox через ListFiles
  - Добавить файл → диалог выбора файла → ContainerManager.AddFile → обновить ListBox
  - Извлечь файл → взять выбранный в ListBox → диалог куда сохранить → ContainerManager.ExtractFile
  - Удалить файл → взять выбранный в ListBox → подтверждение → ContainerManager.DeleteFile → обновить ListBox
  - Проверить целостность → ContainerManager.CheckIntegrity → показать результат в Label
