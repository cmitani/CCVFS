# CCVFS

CCVFS — Windows-приложение для создания и управления зашифрованными файловыми контейнерами.

Проект создан как курсовая работа и сейчас представляет собой рабочий прототип для изучения файловых форматов, блочного хранения данных, криптографии, проверки целостности и разработки Windows Forms-приложений.

## Возможности

- создание контейнера `.ccvfs` заданного размера;
- открытие контейнера по паролю;
- использование дополнительного key-файла;
- добавление файлов в контейнер;
- извлечение файлов из контейнера;
- удаление файлов и освобождение занятых блоков;
- отображение содержимого контейнера;
- проверка целостности контейнера;
- шифрование блоков через AES-GCM;
- получение ключа через PBKDF2-HMAC-SHA256;
- проверка целостности через HMAC-SHA256;
- параллельное шифрование блоков при добавлении файлов.

## Архитектура

Контейнер состоит из заголовка, bitmap занятых блоков, зашифрованной директории и зашифрованных блоков данных.

Для каждого файла сохраняются:

- имя файла;
- исходный размер;
- список блоков, в которых находятся его данные.

Каждый блок данных хранит ciphertext, nonce и authentication tag. При открытии контейнера проверяются его формат, пароль или key-файл и HMAC всего контейнера.

Основные компоненты:

- `MainForm` — графический интерфейс;
- `ContainerManager` — создание, открытие, добавление, извлечение и удаление файлов;
- `Crypto` — PBKDF2, AES-GCM и HMAC;
- `Bitmap` — карта свободных и занятых блоков;
- `Entry` — запись о файле внутри контейнера;
- `Header` — заголовок файла контейнера;
- `ContainerSession` — состояние открытого контейнера.

## Сборка и запуск

Из папки проекта выполни:

```powershell
dotnet restore
dotnet build
dotnet run
```

Проект собирается под `net8.0-windows` и запускается как Windows Forms-приложение.

## Тестирование

Пока в проекте нет полноценного набора автоматических тестов. Для ручной проверки нужно протестировать создание контейнера, открытие с правильным и неправильным паролем, добавление, извлечение, удаление файлов и проверку повреждённого контейнера.

Полноценные тесты планируется вынести в отдельный проект, например `CCVFS.Tests`, и запускать их командой:

```powershell
dotnet test
```

Тесты должны покрывать криптографические функции, сериализацию заголовка и директории, работу bitmap, операции с файлами, key-файлы, ошибки доступа и повреждение данных.

## Важное замечание о безопасности

Это учебный прототип, а не готовая production-система для хранения критически важных данных. Перед практическим использованием необходимо отдельно проверить формат файла, очистку памяти, обработку ошибок, политику паролей, утечки метаданных, безопасное удаление данных и восстановление после повреждения контейнера.

## Roadmap

1. Исправить известные крайние случаи и добавить полноценные автоматические тесты для всех основных операций приложения.
2. Вынести тесты в отдельный проект `CCVFS.Tests` и настроить их автоматический запуск через CI.
3. Привести все публичные поля и методы к единому стилю именования PascalCase.
4. Добавить потоковую обработку больших файлов, чтобы не загружать весь файл или большое количество блоков в память.
5. Добавить полноценную проверку версии формата контейнера и систему миграций для будущих изменений.
6. Улучшить обработку ошибок и проверку путей, дубликатов файлов, свободного места и повреждённой метаинформации.
7. Добавить отображение прогресса и отмену долгих операций.
8. Добавить поиск, сортировку, отображение метаданных файлов и drag-and-drop.
9. Добавить безопасную очистку или перезапись освобождённых блоков там, где это возможно.
10. Сделать настраиваемыми параметры криптографии и добавить проверку надёжности пароля.
11. Добавить упаковку релизов, воспроизводимые сборки и автоматические проверки проекта.
